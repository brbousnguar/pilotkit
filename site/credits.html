Spend less

  • Ask one precise question rather than several vague ones: every model call re-sends the whole chat.
  • Start a new chat for a new subject. A long chat gets more expensive with every question.
  • Models differ in price: hover a model in the chat's model list to see its credits per million tokens, in and out.
  • Name the issue key or paste the page link: the assistant reads one item instead of searching.
