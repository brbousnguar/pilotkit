Checking this PC…

Four ways to ask

  1. This desk

    The simplest: type a question on the Chat page. Every answer shows the AI credits it cost and which tools it used. Open it again any time with:

    pilotkit start

  2. VS Code, in Copilot Chat

    Open Copilot Chat (Ctrl+Alt+I, ⌃⌘I on a Mac), switch the mode to Agent, then click the tools icon: pilotkit is in the list. The first time, VS Code asks you to trust and start the server; say yes.

    Name the source when it helps: "Use pilotkit to list my open Jira issues."

  3. The terminal, with the Copilot CLI

    Run copilot in any folder and ask. Copilot asks before each tool call; allow the pilotkit tools for the session. For a single question, allow them up front (they only read):

    copilot -p "Summarize the Jira issue KEY-123" --allow-tool=pilotkit

  4. The GitHub Copilot app

    copilot app opens it. If pilotkit is not in its tool list, add an MCP server there with the command pilotkit mcp.

Questions that work well

  • What are my open Jira issues, by priority?
  • Which issues in project KEY changed this week, and who changed them?
  • Summarize KEY-123: the problem, what was tried, and what is still open.
  • Find the Confluence page about the deployment process and list its steps.
  • Draft a comment for KEY-123 asking for the missing test data. (pilotkit only reads: you paste the comment yourself.)

What pilotkit can and cannot do

  • It reads Jira and Confluence with your own Atlassian account: you see what you could see in the browser, nothing more.
  • It never writes: no comment, transition or page edit. Ask for a draft and paste it.
  • Your Atlassian API token stays protected on this PC: in the macOS Keychain, in a file only your Windows account can decrypt (DPAPI), or in the Linux Secret Service. Never in a config file.
  • The desk only answers on 127.0.0.1: nobody else on the network can reach it.

When something is off

pilotkit doctor checks Copilot, Atlassian and both registrations, and says what to run. pilotkit setup again fixes most things; pilotkit setup --new-token replaces an expired Atlassian token.

Atlassian API tokens are created at id.atlassian.com → Security → API tokens.
