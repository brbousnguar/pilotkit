Your Copilot can read your work tools

pilotkit setup connected your GitHub Copilot seat to the systems you added once, on this PC. Here are the four places you can now ask.

Checking this PC…

Four ways to ask

  1. This desk

    The simplest: type a question on the chat. Every answer shows the AI credits it cost and the tools it used. Open it again any time with:

    pilotkit start

  2. VS Code, in Copilot Chat

    Open Copilot Chat (Ctrl+Alt+I, ⌃⌘I on a Mac), switch the mode to Agent, then click the tools icon: the pilotkit servers are in the list. The first time, VS Code asks you to trust and start each server; say yes.

    Name the source when it helps: "Use pilotkit to list my open Jira issues."

  3. The terminal, with the Copilot CLI

    Run copilot in any folder and ask. Copilot asks before each tool call; allow the pilotkit tools for the session. For a single question, allow them up front (they only read):

    copilot -p "Summarize the Jira issue KEY-123" --allow-tool=pilotkit-atlassian

  4. The GitHub Copilot app

    copilot app opens it. If a pilotkit server is not in its tool list, add an MCP server there with the command pilotkit mcp atlassian.

Questions that work well

What pilotkit can and cannot do

  • It never writes: no comment, update or edit in any system. Ask for a draft and paste it yourself.
  • The desk only answers on 127.0.0.1: nobody else on the network can reach it.

When something is off

pilotkit doctor checks Copilot, every connected system and both registrations, and says what to run. pilotkit setup again fixes most things.
